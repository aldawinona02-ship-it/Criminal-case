# THE LAST CASE — Criminal Case Mystery Game

An interactive, 3D browser-based sci-fi murder mystery game featuring real-time clue analysis, suspect interrogation, evidence board deductions, and atmospheric sound design.

🎮 **[Play the Game Live](https://aldawinona02-ship-it.github.io/Criminal-case/)**

---

## 🕹️ How to Play
Click the live link above to play directly in your web browser. No download or installation is required!

1. **Round 1 — Initial Crime Scene Investigation**: Examine physical evidence and interrogate suspects.
2. **Round 2 — Timeline Reconstruction & Surveillance Footage**: Analyze time records and uncover contradictions.
3. **Round 3 — The Final Deduction & Project 9**: Reconstruct the evidence connection web on the Evidence Board and formulate the final accusation.

---

## 🛠️ Built With
- Pure HTML5 / CSS3 / Vanilla JavaScript
- **Three.js** & OrbitControls (3D Crime Scene Visualization)
- **Web Audio API** (Procedural ambient audio & cinematic sound effects)
- Hosted directly via **GitHub Pages**
