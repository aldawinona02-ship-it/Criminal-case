# THE LAST CASE — Criminal Case Mystery Game

An interactive, 3D browser-based sci-fi murder mystery game codebase featuring clue analysis, suspect interrogation, evidence board deductions, and audio design.

---

## 📁 Project Structure
- `index.html` - Game structure and modals
- `game.js` - Core game engine & state management
- `scene3d.js` - Three.js 3D crime scene rendering
- `audio.js` - Sound engine (Web Audio API)
- `gameData*.js` - Rounds 1, 2, and 3 scenario and evidence data
- `styles.css` - UI theme and layout styling

---

## 🛠️ Built With
- Pure HTML5 / CSS3 / Vanilla JavaScript
- Three.js & OrbitControls
- Web Audio API
